# Angelica Chowdhury - research site

Static site for [angie0angie.nekoweb.org](https://angie0angie.nekoweb.org). No build step.

## Files

- `index.html` - page content
- `style.css` - layout and visual design
- `rainforest.jpg` - fixed page background and image in the Other section

## Upload to Nekoweb

1. Sign in at [nekoweb.org](https://nekoweb.org).
2. Open your site **angie0angie**.
3. Upload all three files above into the **root** of the site (the same folder, not a subfolder).
4. Visit [https://angie0angie.nekoweb.org](https://angie0angie.nekoweb.org).

If the page looks unstyled or has no background, make sure `style.css` and `rainforest.jpg`
are next to `index.html`.

## Things still to personalise

- Replace the temporary text in “Some recent tunes I’m enjoying” with tracks or a playlist link.
- Add more images to the photo section when you want a gallery.
- Add links to research papers when their public URLs are available.

## Free custom domain later (optional)

`angie0angie.nekoweb.org` already works. Do not use `username.github.io` for Nekoweb.

To add something like `yourname.is-a.dev`:

1. In Nekoweb, add the custom domain.
2. Register it at [is-a.dev](https://github.com/is-a-dev/register) with a CNAME to `angie0angie.nekoweb.org`.
